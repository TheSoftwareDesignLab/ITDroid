ITDroid Report

Evaluated applications

Pick an application on the left to see its results: internationalization presentation failures (IPFs) per language with the screens where they appear, the hardcoded strings found in the code, how long each phase took and what the machine was doing, and the static facts of the run (APK, device, translation model, configuration).

The list comes from the results folder served by java -jar target/ITDroid-1.0.0.jar --report [folder]; every sub-folder with a report.json is one evaluation.

This page needs the ITDroid report server. Browsers do not let a page opened from disk read the results, so start it from the ITDroid folder and open the address it prints: 
java -jar target/ITDroid-1.0.0.jar --report           # serves results/
java -jar target/ITDroid-1.0.0.jar --report path/to/folder   # any folder with evaluations
